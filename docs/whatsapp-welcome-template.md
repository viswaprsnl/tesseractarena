# WhatsApp Welcome / First-Reply Template

This is the arena's standard first-reply when a lead messages the
WhatsApp Business number (+91 99081 16444). Paste it as the auto-reply
in **WhatsApp Business → Business tools → Greeting message** (fires on
first contact from a new conversation), or copy-paste manually when
replying to a cold lead.

## Format

- Keep emoji inline — WhatsApp renders them fine.
- Replace `{Name}` with the lead's first name if you're replying by hand.
  If this is set up as an automated greeting, drop the `{Name}` part and
  start with `Hi 👋` instead.
- The Google Maps link below is the arena's live place URL. If you have
  a shorter `maps.app.goo.gl/…` share link (generate from Google Maps →
  Share → Copy link), swap it in — same destination, cleaner preview.
- "Experiences start at ₹699/person" is the marketing-facing entry
  price. Make sure you have a package or coupon that actually honours
  this before this template goes live, otherwise leads will arrive at
  the booking page and see higher prices.
